🧱 FFmpeg: la base imprescindible

O FFmpeg es la herramienta que corta y renderiza video por debajo de todo; es la base de Remotion, que Hyperframes usa para montar el motion. Es el único elemento verdaderamente obligatorio del cuerpo: sin él, nada funciona. La instalación cambia un poco según el sistema operativo.

Objetivo: instalar FFmpeg en tu sistema. Elige la línea de tu SO (las demás están comentadas con #) y pégalo en la terminal.

terminal · instalar FFmpeg 
# macOS (Homebrew)
brew install ffmpeg

# Ubuntu / Debian
sudo apt update && sudo apt install -y ffmpeg

# Windows (PowerShell, com winget)
winget install --id Gyan.FFmpeg -e

Cómo verificar

Ejecuta el comando de abajo. Debe aparecer una línea que empiece con ffmpeg version .... Si aparece "comando no encontrado", vuelve a abrir la terminal (o la sesión) e inténtalo de nuevo.

ffmpeg -version
Qué es

La herramienta de corte y renderizado que es la base de Remotion/Hyperframes.

Por qué aprender

Es el único elemento realmente obligatorio; sin él nada funciona.

Conceptos clave

FFmpeg, renderizado, dependencia del sistema.

2

⚙️ Hyperframes: el motor de motion

O Hyperframes es el segundo imprescindible: es el motor que monta las animaciones (motion graphics) del reel: texto que entra con punch, chips, reveals. Se ejecuta mediante npx, así que no hace falta una instalación pesada; el propio comando lo descarga y lo ejecuta en el momento.

¿Nuevo por aquí? — «npx»

npx es un atajo que viene incluido con Node.js: ejecuta un paquete sin que tengas que instalarlo permanentemente. La primera vez puede descargar algunos archivos; es normal y solo ocurre una vez.

Objetivo: confirma que Hyperframes responda en tu máquina.

terminal · comprobar Hyperframes 
npx hyperframes --version

Cómo verificar

El comando debe imprimir un número de versión (algo como 2.x.x). Si te pregunta si quieres instalar el paquete la primera vez, acepta. Si da un error de npx no encontrado, instala Node.js antes.

Qué es

El motor que crea el motion del reel; se ejecuta mediante npx.

Por qué aprender

Sin él no hay motion graphics; un comando confirma que está activo.

Conceptos clave

Hyperframes, npx, motion graphics.

3

🧠 Groq: la revisión que menos inventa

O Groq es gratis y muy recomendado para la transcripción (base de los subtítulos) y para la revisión — en la práctica, es lo que menos «inventa» en esta tarea. No hace falta instalar nada: basta con tener la clave de API disponible como variable de entorno llamada GROQ_API_KEY.

Objetivo: comprueba si la clave ya está en el entorno y, si no, defínela. Cambia el valor de ejemplo por tu clave real.

terminal · GROQ_API_KEY 
# 1) já está definida? (deve imprimir a chave)
printenv GROQ_API_KEY

# 2) se não imprimiu nada, defina (troque pela sua chave)
export GROQ_API_KEY="<sua-chave-gsk_...>"

Cómo verificar

Después del export, ejecuta printenv GROQ_API_KEY de nuevo: ahora debería imprimir tu clave (que empieza con gsk_). Para no repetirlo en cada sesión, coloca el export en tu ~/.bashrc o ~/.zshrc.

Por qué aprender: una variable de entorno vacía es el error silencioso más común aquí: el reel se procesa, pero los subtítulos salen peor. Revisarla antes evita retrabajo. Conceptos clave: Groq, GROQ_API_KEY, variable de entorno.

4

➕ Opcionales: fal.ai, Firecrawl, /watch

Estos tres no son obligatorios: activa solo lo que tu perfil necesite, y nada de pago se incluye sin tu "sí". Si falta alguno, el motor se degrada con elegancia en lugar de bloquearse.

🖼️

fal.ai (imagen con IA · de pago)

Genera imágenes para cold opens e insertos. Como es de pago, solo se incluye si lo apruebas explícitamente.

🌐

Firecrawl (B-roll real · gratis)

Trae capturas reales de sitios/repositorios que mencionas, para usarlas como B-roll real en lugar de imágenes genéricas.

👁️

/watch (QC visual)

Hace el control de calidad revisando los fotogramas del reel; ayuda al revisor a detectar huecos y superposiciones.

Objetivo: si tu perfil requiere fal.ai y/o Firecrawl, define las claves (opt-in). Omite las que no uses.

terminal · claves opcionales 
# só se o seu perfil usar imagem por IA (pago)
export FAL_KEY="<sua-chave-fal>"

# só se o seu perfil usar B-roll real (grátis)
export FIRECRAWL_API_KEY="<sua-chave-firecrawl>"

Cómo verificar

Confirma con printenv FAL_KEY o printenv FIRECRAWL_API_KEY. ¿No definiste ninguna? No hay problema — el diagnóstico del entorno (módulo 3.2) solo te pedirá lo que tu perfil realmente necesite.

Conceptos clave: fal.ai, Firecrawl, /watch, opt-in (tú apruebas antes de activar).

5

📦 Instalar la .skill

Con el stack en su lugar, falta cargar la meta-skill en Claude. El archivo tiene extensión .skill. Hay dos caminos; usa el que te resulte más sencillo.

⬇️ Descargar forja-reel.skill

El archivo (y la guía de uso) queda en el repo videos-edit-cria.

Ruta A — doble clic

Después de descargar, da doble clic en el archivo forja-reel.skill. Claude lo reconoce y ofrece cargar la habilidad.

Ruta B — mediante los conectores

  1. Abre el Claude.
  2. Ve a conectores → skills.
  3. Elección cargar habilidad y apunta al .skill.

Cómo verificar

En la lista de skills de Claude debe aparecer la habilidad de Forja Reel disponible. Si no apareció, comprueba que descargaste el archivo completo (no la página) y repite el Camino B.

Conceptos clave: archivo .skill, conectores, cargar habilidad.

6

▶️ Activar con "Forja Reel" y usar Opus

Skill cargada, solo tienes que llamarla. Tú activa la meta-skill escribiendo "Forja Reel" en la conversación con Claude. Un detalle que hace la diferencia: usa el modelo Opus, no Sonnet — la entrevista y las decisiones de identidad quedan mucho más consistentes.

Objetivo: iniciar la meta-skill. Con Opus seleccionado en Claude, envía este mensaje.

Claude (modelo: Opus) · mensaje 
Forja Reel

Cómo verificar

La skill responde iniciando la entrevista — aparece la primera pregunta de los 8 bloques. Si en cambio recibes una respuesta genérica, confirma que la skill esté cargada (tema 5) y que hayas escrito el nombre exacto.

Por qué Opus y no Sonnet

La entrevista pide razonamiento para recomendar buenas opciones de identidad y armar el perfil.json. El modelo más potente guía mejor esta conversación y se equivoca menos en las decisiones — vale la pena cambiarlo antes de empezar.

Conceptos clave: activación, Opus, entrevista. En el módulo 3.2 entramos en detalle en la entrevista.
